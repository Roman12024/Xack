Введение

Эта страница — материалы для разработчиков: визуальные токены и компоненты CRM «ИТ Школа Ростелеком», оформленные по корпоративной дизайн-системе Ростелекома (2-е поколение, «Атомаро»), в теме Rostelecom Light Theme (присутствует и тёмная тема). Все значения заданы CSS-переменными (--rt-*) и используются в static/style.css. Аналог продукта: LMS «ИТ Школа Ростелеком — Код будущего».

Подключение в проекте

Все токены и компоненты уже подключены в static/style.css. Пример использования токенов в собственных стилях:

.my-block {
  background: var(--rt-bg-surface);
  color: var(--rt-text-primary);
  border: 1px solid var(--rt-border);
  border-radius: var(--rt-radius-l);
  padding: var(--rt-space-4);
}
.my-block:hover { border-color: var(--rt-primary); }

Тема переключается атрибутом data-rt-theme="light|dark" на теге <html> — все семантические токены пересчитаются автоматически.
